**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it.

- Settings > About > Join the community: nightly, `discord.gg/pSqgRU3YP9`, and a QR code that opens
  `https://discord.gg/pSqgRU3YP9`.
- The empty library mentions it once, the first time it is shown, and never again.

**Testers:** ask for help and say what breaks on the [nightly Discord](https://discord.gg/pSqgRU3YP9). After starting
a Ren'Py game, please send `/data/dulcamara/logs/dulcamara.log` (and `dulcamara.old.log` beside it), whether it plays
or not, and say which game and which version of it (PC, Mac or Linux build).

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
