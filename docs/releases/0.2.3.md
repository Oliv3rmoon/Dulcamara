A test build for Ren'Py on the PS5. 0.2.2 still crashed as Python started. Its crash report, read correctly this
time, shows why: Python asks for its current folder (`getcwd`), which a PS5 app's libc does not have, and the
system library the build used for it crashed. Both Ren'Py cores now keep track of the folder themselves. Earlier
crash reports read the registers from the wrong place, so 0.2.2's fix (`readlink`) was not the cause; reports now
read them where the PS5 puts them.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it.

- Fixes the crash as a Ren'Py game started (0.2.0 to 0.2.2).
- Ren'Py's save times (`time.strftime`) use a call known to work on the PS5.
- Crash reports give the right registers and name the system module that crashed.

**Testers:** please send `/data/dulcamara/logs/dulcamara.log` (and `dulcamara.old.log` beside it) after starting a
Ren'Py game, whether it plays or not, and say which game and which version of it (PC, Mac or Linux build). A Ren'Py 7
or 6 game is welcome too.

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
