A test build for Ren'Py on the PS5. 0.2.3 got further: Ren'Py started, and then crashed as it opened its log. The
first line of Ren'Py's log is the time in UTC, and the Ren'Py core's own UTC time left out the time zone's name,
which Python reads without checking. Both Ren'Py cores now always give a zone ("UTC", or the offset for local time),
and they decode the console's text as UTF-8 themselves.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it.

- Fixes the crash as a Ren'Py game started in 0.2.3, after Ren'Py's display had started.
- Ren'Py's times (`time.gmtime`, `time.localtime`) always have a time zone.
- Text Python gets from the console (error messages, time zones) is read as UTF-8.

**Testers:** ask for help and say what breaks on the [nightly Discord](https://discord.gg/pSqgRU3YP9). After starting
a Ren'Py game, please send `/data/dulcamara/logs/dulcamara.log` (and `dulcamara.old.log` beside it), whether it plays
or not, and say which game and which version of it (PC, Mac or Linux build). If it gets past the black screen, the
game's own `log.txt` (in its folder) helps too. A Ren'Py 7 or 6 game is welcome as well.

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
