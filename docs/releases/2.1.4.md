Two optional controls are available in **Settings → Ren’Py**. Both start off on existing installations.

- **Privacy shortcut** reserves R3. Press it to hide the picture, pause gameplay and silence audio. Release the controls, then press and release R3 alone to resume. The privacy screen works in the library and menus too.
- **One-handed controls** supports either hand. Left hand uses L1 to advance or select, L2 to go back, and the D-pad for choices. Right hand uses R1 to advance, Circle to go back, and the right stick for choices. The inputs follow each game’s existing bindings. The Standard setting restores the original layout.

A marked USB library can now open under either `/usb0` or `/mnt/usb0` (and the other numbered ports). If both names point to the same directory, Dulcamara uses it once. If the shared storage mount is missing, Dulcamara also tries its title-local library.

**Installing from 2.1.3.** Enable test builds in **Settings → System**, then choose **Check for updates now**. After the update, open **Settings → About** and look for **2.1.4** and **PPSA75483**.

**Installing from 2.1.2 or earlier.** Extract the full app ZIP into an empty folder. Copy the enclosed `PPSA75483` folder beside `PPSA99010`. Keep the old folder and its saves, since vkQuake uses that title ID. An accessible shared or marked USB library keeps its existing location. If you used the old title’s `/download0/dulcamara` library, the new title may open with an empty library.
