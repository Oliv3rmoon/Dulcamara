Two optional controls are available in **Settings → Ren’Py**. Both start off on existing installations.

- **Privacy shortcut** reserves R3. Press it to hide the picture, pause gameplay and silence audio. Release the controls, then press and release R3 alone to resume. The privacy screen works in the library and menus too.
- **One-handed controls** supports either hand. Left hand uses L1 to advance or select, L2 to go back, and the D-pad for choices. Right hand uses R1 to advance, Circle to go back, and the right stick for choices. The inputs follow each game’s existing bindings. The Standard setting restores the original layout.

The PS5 title ID is **PPSA75483**, introduced in 2.1.3. Install the full folder separately if you have 2.1.2 or earlier. Keep the old PPSA99010 folder and its saves, since vkQuake uses that folder. Shared and marked USB libraries keep their existing locations.

Host tests checked controller input, identical privacy frames in the library and an active game, a paused and empty audio device, and resuming the game. PS5 controller, audio, storage and gameplay still need console testing.
