A test build for Ren'Py on the PS5. In 0.2.7 the controller works in Ren'Py games (the D-pad moves on their menus),
but a game still ends without a crash report as it plays its first OGG sound (a button's hover sound, say). The
build machine plays the same sounds, so 0.2.8 traces, in `dulcamara.log`, each step of Ren'Py's sound and movie
decoding, and anything that ends the app, so that the next log says where it ends.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it.

- Traces the crash 0.2.6 and 0.2.7 had as a Ren'Py game played its first OGG sound.
- Everything 0.2.7 has stays: the controller as Ren'Py's keys, the cursor (L3, and the touchpad), Dulcamara's menu
  with Options held, a game's own keys, Ren'Py's own section in the library and its own page in Settings.

**Testers:** ask for help and say what breaks on the [nightly Discord](https://discord.gg/pSqgRU3YP9). Start a Ren'Py
game and move on its menu until it ends (or plays on), then please send `/data/dulcamara/logs/dulcamara.log` (and
`dulcamara.old.log` beside it), and say which game and which version of it (PC, Mac or Linux build).

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
