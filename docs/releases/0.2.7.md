A test build for Ren'Py on the PS5. 0.2.6 ended a game at once, without a crash report, on the first thing the
controller did in it (the cursor's first move, or the first arrow). 0.2.7 gives the threads Ren'Py starts (one for
each sound it plays) far bigger stacks, and makes a crash in any of them leave a report, and its log now follows what
Ren'Py does (each sound, each focus, each new picture) as it does it.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it.

- Aimed at 0.2.6's crash on a Ren'Py game's first hover.
- A crash in any thread of Ren'Py's is now reported in `dulcamara.log`.
- `dulcamara.log` notes each sound Ren'Py plays, each new focus and each new picture, as they happen.
- Everything 0.2.6 added stays: the controller as Ren'Py's keys, the cursor (L3), a game's own keys (its menu > Keys
  for this game), and Ren'Py games' own section in the library.

**Testers:** ask for help and say what breaks on the [nightly Discord](https://discord.gg/pSqgRU3YP9). After starting
a Ren'Py game, move on its menu (the D-pad, the stick, the cursor with L3), then please send
`/data/dulcamara/logs/dulcamara.log` (and `dulcamara.old.log` beside it), whether it works or not, and say which
game and which version of it (PC, Mac or Linux build).

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
