# Dulcamara Eclipse 2.1.2 · PS5 test build

If the console denies access to `/data/dulcamara/games`, Dulcamara tries its own writable library under `/download0/dulcamara` and shows the selected location. That library starts separately. Your existing games, saves and backups stay in their original folder. For large games, use an accessible USB library with `dulcamara/portable.txt` and `dulcamara/games/`. A marked drive takes priority. Settings → About shows the active games folder.

- Square retries inaccessible storage while the library stays on screen. If a second Ren’Py game needs a fresh process and the console declines the relaunch, the library shows how to reopen the game.
- The Settings shortcut reads **OPTIONS** in both library views. The executable includes a recovery font so the menus and storage errors remain readable if the installed `assets/fonts` folder is missing. The full ZIP contains all six fonts. For an existing 2.1.1 or 2.1.2 installation with only that folder missing, merge the contents of the fonts repair ZIP into the title folder.
- Startup checks for existing save recovery work in the active library. A fresh library can launch without creating an empty transaction folder first. Actual unfinished recovery still protects saves, and Square can retry a failed recovery.
- The build includes itch.io Shelf 1.1 and the game compatibility updates from Eclipse 2.1.1.

**Install.** Enable **Settings → System → Test builds**, then choose **Check for updates now**. If your current installation cannot update, install the complete `PPSA99010` folder from the app ZIP using your usual folder installation method. Keep your game and save folders. Use the complete release when other assets are missing.

**Test on PS5.** Report the version, install method and active games path. Check **OPTIONS → Settings**, launch a game in the active library, save, exit normally, and look for a new entry under **Backups**. Include the last screen or exact error if it stops. Host checks exercised a permission-denied library with the font folder removed, a game launch, a clean stop and an automatic save backup. Console installation, original-library access and installed-file encryption still need hardware verification.
