A test build for Ren'Py on the PS5. 0.2.0 crashed as a Ren'Py 8 game started on a console; this build changes
what most likely caused it, and its log says how far a game gets either way.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it.

- Ren'Py's cores keep an environment of their own instead of the console's, where 0.2.0's crash most likely was.
- `dulcamara.log` lists each step of starting a Ren'Py game ("renpy: step: ..."), so a log shows where a start
  stopped.
- A crash report names the module that crashed (the app or a system module) and the thread.

**Testers:** please send `/data/dulcamara/logs/dulcamara.log` (and `dulcamara.old.log` beside it) after starting a Ren'Py game,
whether it plays or not, and say which game and which version of it (PC, Mac or Linux build).

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
