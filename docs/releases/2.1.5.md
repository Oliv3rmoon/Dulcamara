Dulcamara Eclipse **2.1.5** (`PPSA75483`) restores PS5 sandbox unlock for `/data/dulcamara`, eliminates the Ren’Py Vulkan rendering stalls behind black flashes, fixes the settings and updater lockouts reported during 2.1.x testing, and extends portable libraries to extended storage.

- **PS5 storage & sandbox unlock restored (`PPSA75483`).** Restores single-threaded startup unlock (`ps5_unlock` for etaHEN / LegacyJB / OnionHEN plus the `PPSA75483`-targeted `lapy.elf` helper) so `/data/dulcamara/games`, automatic save backups, and library scanning work again under ShadowMountPlus instead of failing with `Operation not permitted`. **Settings → About** now displays live storage and unlock status.
- **Zero-stall Vulkan rendering for Ren’Py & EasyRPG.** Routes all CPU-rendered game frames through the persistent ring-buffered Vulkan game image even when **Shader** is set to **Off**, reusing the GPU image on repeated frames with zero copy and zero `vkQueueWaitIdle` stalls (fixing the black flashes / black bars seen during 1080p Ren’Py playback) while avoiding double CPU/GPU colour grading.
- **Instant settings persistence & fixed updater.** Toggling **Test builds** (or any setting) writes `settings.ini` immediately instead of waiting for Circle to leave Settings, so closing from the PS5 home menu no longer forgets the toggle. When storage is unavailable, startup recovery now defers cleanly instead of permanently locking **Check for updates now** or showing a misleading save-recovery message on **Install itch.io Shelf**, and **Square** retry refreshes the detected app installation directory.
- **Reset-safe portable libraries on USB & extended storage.** `dulcamara/portable.txt` is now probed on extended storage (`/mnt/ext0`, `/mnt/ext1`) as well as `/usb0..7` and `/mnt/usb0..7`, with duplicate mount aliases deduplicated automatically so your games and saves can live safely off internal `/data`.
- **Includes all 2.1.x fixes and improvements.** Dedicated title ID `PPSA75483` (coexists beside vkQuake’s `PPSA99010`), *Fantasy Opposite* detection, itch.io Shelf 1.1 with PS5 console DNS resolution, *Summertime Saga* 0.20.16 & 21.0.0-wip.8194, *My New Family* 0.14 → Epilogue handoff, *Champion of Realms* 0.113, R3 **Privacy shortcut**, **Left/Right one-handed controls**, embedded Inter fallback font, and the `OPTIONS` Settings glyph.

**Installing from 2.1.3 or 2.1.4 (sandboxed).** If your current 2.1.x build cannot unlock `/data`, extract `PPSA75483.zip` and copy the `PPSA75483` folder over your existing `PPSA75483` installation (or into `/data/homebrew/PPSA75483`). Once 2.1.5 opens, open **Settings → About** to confirm **2.1.5**, **PPSA75483**, and your active storage/unlock status.

**Host verification & console testing notes.** Host suites verified storage selection/deduplication, immediate `Test builds` persistence without leaving Settings, deferred sandbox recovery, Lapy elevation wire/client tests, 2.1.4 → 2.1.5 transactional self-update using the packaged `PPSA75483.zip`, weak-import and PS5 module-import audits (`eboot.bin` + `lapy.elf` manifest SHA-256), and full GPL source archive restoration. Physical PS5 console confirmation is still needed for `/data/dulcamara` unlock on ShadowMountPlus/etaHEN/Lapy, Ren’Py black-flash elimination in gameplay, automatic save backups, and in-app self-update.
