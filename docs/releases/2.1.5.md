Dulcamara Eclipse **2.1.5** (`PPSA75483`) restores PS5 sandbox unlock for `/data/dulcamara`, eliminates the PS5 close-app kernel panics, auto-relaunch loop, `ENOSYS` backup/download errors, remaining Ren’Py black flashes, and *Champion of Realms* `freebsd` crash reported in 2.1.x testing, and extends portable libraries to extended storage.

- **PS5 close-app & overlay stability.** `plat_in_background()` now pauses game execution, drains the RADV Vulkan GPU queue (`vkDeviceWaitIdle`), and pauses SDL audio the instant the PS5 Control Center / system UI overlay opens (`system_ui_overlaid`) or the app enters background, and in-app **Close Dulcamara** stops background scanner/cover workers and closes PS5 joysticks before tearing down Vulkan.
- **No more auto-launching the last game on relaunch.** Consumes `restart-game.txt` immediately before deferred `app_start_game()`, removes the handoff if `sceSystemServiceLoadExec` fails, and automatically clears stale handoffs older than 60 seconds so normal relaunches always open your library.
- **Automatic save backups, self-updates & itch.io Shelf downloads fixed on PS5.** Tolerates `ENOSYS` / `EINVAL` / `ENOTSUP` on `fsync()`, `statvfs()`, and `fcntl.flock()` (switching PS5 free-space checks to `_fstatfs` while keeping real I/O and out-of-space errors fail-closed), fixing both `Backup failed (Function not implemented)` and itch.io Shelf’s `Could not read or write the download` — including for already-installed itch.io Shelf folders.
- **Champion of Realms 0.113 & PC Ren’Py platform compatibility.** Ren’Py 8 & 7 boot scripts now report standard Linux platform metadata (`sys.platform = "linux"`, `platform.system() == "Linux"`) on PS5 instead of `"freebsd"`, fixing `Exception: Piattaforma non supportata: freebsd` and similar PC game platform guards.
- **PS5 storage & sandbox unlock restored (`PPSA75483`).** Restores single-threaded startup unlock (`ps5_unlock` for etaHEN / LegacyJB / OnionHEN plus the `PPSA75483`-targeted `lapy.elf` helper) so `/data/dulcamara/games`, automatic save backups, and library scanning work again under ShadowMountPlus instead of failing with `Operation not permitted`. **Settings → About** now displays live storage and unlock status.
- **Double-buffered zero-stall Vulkan rendering for Ren’Py & EasyRPG.** Double-buffers `V.soft_image[FRAMES]` per in-flight swapchain frame slot with generation tracking so uploading frame *N* never races with RADV sampling frame *N−1*’s image, eliminating the remaining intermittent black flashes while reusing unchanged frames with zero copy and zero `vkQueueWaitIdle` stalls.
- **Instant settings persistence & fixed updater.** Toggling **Test builds** (or any setting) writes `settings.ini` immediately instead of waiting for Circle to leave Settings, so closing from the PS5 home menu no longer forgets the toggle. When storage is unavailable, startup recovery now defers cleanly instead of permanently locking **Check for updates now** or showing a misleading save-recovery message on **Install itch.io Shelf**, and **Square** retry refreshes the detected app installation directory.
- **Reset-safe portable libraries on USB & extended storage.** `dulcamara/portable.txt` is now probed on extended storage (`/mnt/ext0`, `/mnt/ext1`) as well as `/usb0..7` and `/mnt/usb0..7`, with duplicate mount aliases deduplicated automatically so your games and saves can live safely off internal `/data`.
- **Includes all 2.1.x fixes and improvements.** Dedicated title ID `PPSA75483` (coexists beside vkQuake’s `PPSA99010`), *Fantasy Opposite* detection, itch.io Shelf 1.1 with PS5 console DNS resolution, *Summertime Saga* 0.20.16 & 21.0.0-wip.8194, *My New Family* 0.14 → Epilogue handoff, *Champion of Realms* 0.113, R3 **Privacy shortcut**, **Left/Right one-handed controls**, embedded Inter fallback font, and the `OPTIONS` Settings glyph.

**Installing or updating to refreshed 2.1.5.** Extract `PPSA75483.zip` and copy the `PPSA75483` folder over your existing `PPSA75483` installation (or into `/data/homebrew/PPSA75483`). Once 2.1.5 opens, open **Settings → About** to confirm **2.1.5**, **PPSA75483**, and your active storage/unlock status.

**Host verification & console testing notes.** Host suites verified PS5 `ENOSYS` `fsync`/`statvfs`/`flock` compatibility with `EIO` fail-closed controls, `restart-game.txt` single-consumption & staleness cleanup, Ren’Py `freebsd` → `linux` platform normalization, immediate `Test builds` persistence, deferred sandbox recovery, Lapy elevation wire/client tests, 2.1.4 → 2.1.5 transactional self-update using the packaged `PPSA75483.zip`, weak-import and PS5 module-import audits (`eboot.bin` + `lapy.elf` manifest SHA-256), and full GPL source archive restoration.
