A test build for Ren'Py on the PS5. 0.2.1 still crashed as Python started; its log showed why. Python's start calls
`readlink`, which a PS5 app cannot call the way the build linked it, and that call crashed. Both Ren'Py cores now
answer it (and the other calls of that kind) themselves.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it.

- Fixes the crash as a Ren'Py game started (0.2.0 and 0.2.1).
- Closing a Ren'Py 7 game could hang it; Ren'Py now quits the way its own Quit does.
- `dulcamara.log` lists each step of starting a Ren'Py game, now with Python's two parts.
- Crash reports give the registers and the module that crashed.

**Testers:** please send `/data/dulcamara/logs/dulcamara.log` (and `dulcamara.old.log` beside it) after starting a
Ren'Py game, whether it plays or not, and say which game and which version of it (PC, Mac or Linux build). A Ren'Py 7
or 6 game is welcome too.

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
