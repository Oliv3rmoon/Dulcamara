**Nightshade Station 1.6.0: the first Nightshade Station, based on SwanStationPS5 1.5.9.** Nightshade Station is Oliv3rmoon's release of SwanStationPS5 by darkxex, built on SwanStation: SwanStationPS5 1.5.9 with a new name, Nightshade's look and updates from this repository.

## What changed

- **The name.** The PS5 home screen, the shelf, the About page, the update texts, the notifications and every message say Nightshade Station, in all five languages, and so does the phone page.
- **The look.** A Nightshade theme, the default: near-black pages and panels, a red accent for the focus and the switches, and a near-black sky with a low red glow behind the shelf. Classic, Neon Arcade, Memory Card, Memory Card Dark, Record Shelf and Grayrat are still in Settings > Library > Theme.
- **The art.** The nightshade flower on a black disc for the icon, and a new home background and launch picture, drawn in Nightshade's style.
- **Updates from this repository.** The app asks [Oliv3rmoon/Nightshade-Station](https://github.com/Oliv3rmoon/Nightshade-Station/releases) for a newer release that is not a pre-release and installs it after checking `PPSA98510.zip` against `SHA256SUMS`. It never offers SwanStationPS5's own releases.
- **What stays.** The title ID (PPSA98510) and `/data/SwanStationPS5`, so it installs over SwanStationPS5 and keeps your memory cards, saves, save states, covers and settings. Everything else is SwanStationPS5 1.5.9.

Built and checked by the host tests; not yet run on a console.

## Install

- `PPSA98510.zip`: close SwanStationPS5, extract the ZIP and copy its `PPSA98510` folder over your current one (usually `/data/homebrew/PPSA98510`). SwanStationPS5 doesn't offer this release itself, so this one is copied by hand, or installed by Nightshade's Settings > Apps; from it on, the update check applies the next one. At the first start, ✕ starts from the factory settings in the Nightshade theme, ○ keeps your settings.
- `SwanStationPS5-DiscDaemon.elf`: the disc daemon, sent once to the console's ELF loader (port 9021), as before.
- `SHA256SUMS`: the checksums of both. `gh attestation verify PPSA98510.zip -R Oliv3rmoon/Nightshade-Station` checks that this repository's workflow built it.
- To go back, copy an official [SwanStationPS5 release](https://github.com/darkxex/SwanStationPS5/releases) over it the same way.
