A test build for Ren'Py on the PS5. 0.2.10 got Ren'Py 7 games to start, and one played in game on a console.
0.2.11 is aimed at the white error screen ("can't start new thread") a session could end in, and adds a way to find
where the black flashes are.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder each (a Ren'Py
game's whole folder). No games come with it. With **Settings > System > Test builds** on, 0.2.10 offers this update
itself.

- Should stop the white error screen after playing a while: the game's autosave needed a new thread and the console
  had no memory left for one. Python now keeps its objects in Dulcamara's own memory instead, and if a thread is
  still refused, the autosave is made without one.
- **Black flashes:** the log now notes each black flash it finds in the game's picture, with where it is on the
  screen. If you still see them, that tells whether they come from the game's drawing or from how Dulcamara shows it.
- Not yet tried on a console. Everything 0.2.10 has stays.

**Testers:** ask for help and say what breaks on the [nightly Discord](https://discord.gg/pSqgRU3YP9). Please send
`/data/dulcamara/logs/dulcamara.log` (and `dulcamara.old.log` beside it) after playing until the flashes show, and:

- a short video of the flashing: the Create button's "Save recent gameplay", or a clip from the share menu;
- a screenshot (Create button) where text is missing, and which text should be there;
- which game, which version of it (PC, Mac or Linux build), and whether it is Ren'Py 7 or 8.

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
