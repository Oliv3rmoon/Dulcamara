Dulcamara Eclipse 2.1.3 has its own PS5 title ID, **PPSA75483**. Nahida spotted that earlier Dulcamara releases and vkQuake both installed into PPSA99010. Thanks for catching it.

**First install from 2.1.2 or earlier.** Download the full PPSA75483.zip and extract it into an empty staging folder. Copy the enclosed PPSA75483 folder into your usual homebrew directory, beside PPSA99010. Keep the complete old folder, including vkQuake, its game data, and any older Dulcamara installation. Launch the new Dulcamara entry and check OPTIONS → Settings → About for **2.1.3** and **PPSA75483**. Earlier updaters use a different archive name, so this first install is manual.

**Games and saves.** The shared Dulcamara library still uses `/data/dulcamara` when accessible. The marked USB library also works as before. The fallback under `/download0/dulcamara` belongs to the running title, so the new title may start with an empty fallback library. Keep the old installation for any export you need. The new build leaves the old title’s files in place and does not repair files previously overwritten by a mixed install.

**PS5 retest.** Please report whether both entries launch separately, the version and active games folder shown in About, and what happens when you select Search storage. If you can start a game, make a save, exit normally, and check Backups for a new entry. This test build includes the 2.1.2 fixes for missing fonts, storage retries and the Settings shortcut. Console coexistence, gameplay and installed-file encryption still need hardware verification.
