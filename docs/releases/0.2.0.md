Ren'Py visual novels (Ren'Py 8, 7 and 6) in Dulcamara, on Ren'Py itself, beside the RPG Maker 2000 and 2003 games
of 0.1.0.

**Install:** unzip `PPSA99010.zip` and copy its `PPSA99010` folder to `/data/homebrew/` with permissions `777`
(or let Nightshade's Settings > Apps do it). Put your games in `/data/dulcamara/games/`, one folder (or
`.zip`) each. No games come with it.

- Ren'Py games are found by their `game/` folder, with their launcher's name and their main menu as the cover, and
  each runs on the Ren'Py it was made with: Ren'Py 8.5 (with Python 3.12), or Ren'Py 7.8 (with Python 2.7) for
  Ren'Py 7 and 6 games. Copy a game's whole folder: its `renpy/` or `lib/` folder tells which Ren'Py it needs.
- Cross on, Circle the game's menu, L1 / R1 back and forward, R2 fast-forwards and skips read text, the touchpad is
  the mouse (a tap clicks); saves in `/data/dulcamara/saves/renpy`. Each core keeps its own buttons.
- Ren'Py runs one game each time the app starts: opening another Ren'Py game starts the app again.

Check the download with `gh attestation verify PPSA99010.zip -R Oliv3rmoon/Dulcamara`, or against
`SHA256SUMS`.
