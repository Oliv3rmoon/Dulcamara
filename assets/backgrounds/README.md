# Eclipse ASCII background

`eclipse-ascii-imagegen.png` was created for Dulcamara Eclipse with the built-in ImageGen tool at Andrew's request on 2026-11-08. It is the background plate for the application's animated ASCII presentation. The renderer adds live motion; this PNG itself is a still image. The existing project license applies.

Generation prompt:

Use case: stylized-concept. Asset type: a production background plate for the Dulcamara Eclipse game-library app, landscape 16:9, 1920x1080 composition. Create a striking, sophisticated ASCII-art eclipse in a near-black and deep crimson palette. The entire visible eclipse corona, arcs and flowing particle trails must be made of small crisp monospaced ASCII characters such as . : + * # / \\ | - = < >, with carefully varied glyph density; no smooth painted objects. An enormous shadowed eclipse with a thin, broken crimson corona and orbital streams of red ASCII glyphs drifting across the outer field, subtle stars and scanline texture. The central area must remain very dark and quiet because a large cover card and its title will be drawn over it; carry the interesting red glyph patterns around the upper/side margins and lower background, leaving the top header and bottom control strip easy to read. Low overall brightness with a few restrained scarlet highlights, dark red glows only around glyphs, elegant terminal-art aesthetic, atmospheric and dimensional but genuinely made from text symbols. This plate will be animated in code with a slow pulse, subtle movement and live ASCII particles. No UI, no game covers, no border, no words or logos, no title, no watermark, no green/blue/purple. Opaque near-black background.
